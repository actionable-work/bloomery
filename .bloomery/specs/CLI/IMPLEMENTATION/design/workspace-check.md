# Nix workspace check

The `.bloomery/` directory is optional for a Rust workspace. When it is
present, `mkWorkspace` adds a `bloomery:check` check to its `checks` output; its
presence is the only workspace-specific condition (subject to the global
`checks.enable` option). The check uses the
`bloomery` package output from the Bloomery flake input, enters the workspace
source root, and runs `bloomery check` there. A local binary target named
`bloomery` is neither required nor used.

`mkFlake` forwards the checks generated by `mkWorkspace`, so the same check is
available from `nix flake check` without additional flake configuration. The
workspace `checks.enable` option gates it along with the other generated
checks. `includePackageChecks` does not control this check: the input flake's
CLI package is a dependency of the check, rather than a separate workspace
package-build check.

This Nix integration owns build and command orchestration. The Rust CLI remains
read-only and does not invoke tests, build derivations, or launch other
applications itself.
