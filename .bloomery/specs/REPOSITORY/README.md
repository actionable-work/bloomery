# REPOSITORY Area

This area is optional. A repository may include it when a maintained map of
its physical layout is useful; repositories without it remain valid Bloomery
workspaces. In this repository, the [Layout](LAYOUT/README.md) feature records
the source, Nix, and test-workspace organization.
